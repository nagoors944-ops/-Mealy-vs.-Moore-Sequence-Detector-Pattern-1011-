1. Finite State Machine (FSM): Learned what FSM is and how it works using states, inputs, outputs, and state transitions.

2. Sequence Detection: Learned how to detect a specific binary pattern (1011) from a continuous serial input stream.

3. Overlapping Sequence Detection: Learned how to detect overlapping patterns. For example, the input 1011011 generates two output pulses.

4. Mealy Machine: Learned to design a Mealy FSM, where the output depends on the present state and current input.

5. Moore Machine: Learned to design a Moore FSM, where the output depends only on the present state.

6. State Transition Diagram: Learned to draw state diagrams and understand the transitions between different states.

7. Verilog RTL Coding: Learned to write behavioral Verilog code using parameter or localparam for state encoding.

8. Multi-Process FSM Design: Learned to separate FSM coding into three blocks:
- State Register (sequential logic).
- Next-State Logic (combinational logic).
- Output Logic.
9. Mealy vs. Moore Comparison: Understood the difference in output timing and how Mealy and Moore outputs behave at clock edges.

10. Testbench Development: Learned to write Verilog testbenches to apply deterministic and random input sequences and verify the outputs.

11. Simulation and Waveforms: Learned to simulate RTL designs and observe clk, reset, data_in, mealy_out, and moore_out waveforms using EDA Playground and GTKWave.

12. Functional Verification: Learned to verify whether the sequence detector correctly identifies the pattern and generates the expected output pulses.
